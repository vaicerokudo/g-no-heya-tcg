# Gの部屋 縦スクロールシューティング MVP設計メモ

## 目的

このメモは、Gの部屋 縦スクロールシューティングで最初に作るべき最小構成のMVPを整理するためのもの。

すでに `docs/g-no-heya-game-portal-plan.md` に記録したゲームポータル構想とシューティングの基本方針を前提に、まずは「総長を操作して、敵を倒し、コインを拾い、ボスを倒す」最小体験を作る。

キャラ追加、武器ガチャ、オーラ、ポータル連動は後回しにする。

最優先は、操作して気持ちいいか、縦スクロールシューティングとして成立するかを確認すること。

## 1. MVPの目的

- 総長を操作して敵を倒す基本体験を作る。
- 敵撃破でコインを拾う報酬体験を作る。
- ステージ終盤にボスを出し、撃破でクリアする流れを作る。
- キャラ追加、武器ガチャ、オーラ、ポータル連動は後続フェーズに回す。
- 操作感、攻撃の気持ちよさ、敵との接触ダメージ、コイン回収、ボス戦の成立を優先して確認する。

## 2. 初期MVPの内容

| 項目 | 内容 |
| --- | --- |
| 使用キャラ | 総長のみ |
| ステージ | アストリア草原 |
| 攻撃 | 前方半円斬撃 |
| 敵 | 小型敵、飛行敵、突進敵の3種類 |
| ボス | 星門から出現した大型魔獣 |
| 報酬 | コイン |
| ライフ | HP制 |

ゲームオーバー時も、拾ったコインの一部を持ち帰れる。

クリア時は満額報酬を獲得できる。

## 3. 操作仕様

スマホ/PC両対応を想定する。

- PCではキーボード移動に対応する。
- スマホでは仮想スティック、またはドラッグ移動に対応する。
- 攻撃は自動発動にする。
- 総長は一定間隔で前方半円斬撃を出す。
- プレイヤーは画面下側から中央付近を移動できる。

プレイヤー操作は「避ける」「位置取りする」「コインを拾う」に集中させる。

攻撃ボタンはMVPでは不要。まずは自動攻撃のテンポと移動操作の気持ちよさを確認する。

## 4. 総長の攻撃仕様

通常攻撃は前方半円斬撃。

- 攻撃範囲は扇形、または半円判定にする。
- 攻撃範囲は画面上で可視化する。
- 攻撃にはクールタイムを設定する。
- 攻撃発生時に斬撃エフェクトを表示する。
- 攻撃判定は総長の前方に出す。

レベルアップ要素はMVPでは入れない。攻撃範囲拡大、攻撃速度アップ、斬撃数増加などは後続フェーズで追加する。

## 5. 敵仕様

MVPでは敵を3種類に絞る。

| 敵 | 動き | 役割 |
| --- | --- | --- |
| 小型敵 | まっすぐ下に移動する | 基本敵 |
| 飛行敵 | 左右に揺れながら下に移動する | 横移動への対応を促す敵 |
| 突進敵 | 一定距離まで来るとプレイヤー方向へ突進する | 回避行動を促す敵 |

共通仕様:

- 敵に接触するとプレイヤーがダメージを受ける。
- 敵を倒すとコインを落とす。
- 敵は画面上側、または星門演出から出現する。
- MVPでは敵弾の種類を増やしすぎない。

まずは敵の種類を増やすより、移動、接触、撃破、コイン落下の基本ループを安定させる。

## 6. コイン仕様

敵撃破時にコインを落とす。

- プレイヤーがコインに近づくと回収できる。
- 所持コイン数を画面上に表示する。
- ゲームオーバー時は拾ったコインの一部を持ち帰れる。
- クリア時は拾ったコインを満額獲得できる。

MVPではショップは未実装でよい。コインの使い道より先に、拾う気持ちよさと報酬表示を確認する。

## 7. ボス仕様

ステージ終盤に、星門から出現した大型魔獣を出す。

- ボスはHPを持つ。
- ボスHPバーを表示する。
- 攻撃パターンは1〜2種類に絞る。
- ボス撃破でステージクリアにする。

攻撃パターン案:

- ゆっくり弾をばらまく。
- 一定間隔で突進、または範囲攻撃を行う。

MVPでは複雑なフェーズ変化は入れない。ボスが出て、攻撃を避けながら削り切る体験を優先する。

## 8. 画面構成

MVPで想定する画面:

- タイトル/出撃画面
- ゲーム画面
- クリア画面
- ゲームオーバー画面

MVPでは以下の画面や機能は未実装でよい。

- ショップ
- 鍛冶屋
- 召喚
- キャラ選択
- 武器選択
- オーラ選択
- ポータル連動

## 方針まとめ

最初のMVPでは、総長、アストリア草原、前方半円斬撃、3種類の敵、コイン、ボス戦だけに絞る。

「動かして気持ちいい」「敵を倒して気持ちいい」「コインを拾って嬉しい」「ボスを倒して終わる」という最小の遊びを先に成立させる。
