# Gの部屋ゲームポータル構想メモ

## 目的

Gの部屋TCG、縦スクロールシューティング、落ちものパズルを、ひとつの巨大ゲームへ統合しすぎず、それぞれ独立したゲームとして制作する。

各ゲームは、ポータル、大陸MAP、合言葉、クリアコード、共通施設によってゆるやかにリンクさせる。

今回のメモは今後のゲーム展開方針を記録するものであり、実装方針や既存ルーティングの変更は含まない。

## 1. Gの部屋ゲームポータル構想

将来的に、以下の要素をリンクするゲームポータルを作る。

- Gの部屋TCG
- 星門シューティング
- 星片パズル
- サッグの鍛冶屋
- キャラ図鑑
- BOOTH
- YouTube
- サウンドコミック導線

各ゲームは独立制作し、ポータルや大陸MAPから移動できるようにする。

巨大な単一アプリにすべてを詰め込むのではなく、個別ゲームとして軽く遊べる体験を維持する。ポータルはそれらをつなぐ入口、世界観のハブ、導線として扱う。

## 2. 縦スクロールシューティング構想

仮タイトル候補:

- Gの部屋：星門シューティング
- アストリア防衛戦
- 星門防衛線

基本編成:

- メインキャラ1人
- サポートキャラ1人
- 武器1つ
- 後々、オーラ1つを追加

初期メインキャラは総長にする。

チュートリアル後、初回のみ無料でサポートキャラを1人ランダム召喚する。プレイヤーは総長と初回サポートキャラの組み合わせで初出撃する。

キャラは最初から全員解放しない。星門召喚や条件達成によって少しずつ解放していく。

キャラ解放の流れ:

1. サポートキャラを入手する。
2. サポートキャラとして一緒に出撃する。
3. 専用武器の入手や条件達成を行う。
4. そのキャラをメインとして使用できるようにする。

この流れにより、最初は総長を軸に遊びつつ、少しずつ他キャラへ興味が広がる設計にする。

## 4. サッグの鍛冶屋

武器はサッグの鍛冶屋でランダム鍛造する。

ガチャ的な仕組みではあるが、世界観上は「サッグに武器を作ってもらう」扱いにする。

出た武器種をきっかけに、他キャラも使ってみたくなる導線を作る。たとえば弓が出たことでつつを使ってみたくなる、槍が出たことでうしまるを育てたくなる、といった流れを想定する。

キャラ召喚と武器鍛造は混ぜない。キャラは星門召喚や条件達成、武器はサッグの鍛冶屋というように、入手導線を分ける。

## 5. オーラ構想

防具ではなく、色別オーラを後々の装備/強化要素にする。

オーラはサウンドコミックの物語、キャラカラー、星門、星脈、闇落ちとつなげる。

| オーラ | 効果イメージ |
| --- | --- |
| 白 | 被ダメ軽減 / 回復量アップ |
| 緑 | 攻撃速度 / 貫通力アップ |
| 黒 | 回避 / クリティカルアップ |
| 赤 | 攻撃力アップ / 炎上 |
| 青 | 状態異常 / 毒 / 混乱 |
| 紫 | 弾消し / 防御 / 氷結 |
| 黄 | コイン増加 / ドロップ率アップ |
| 橙 | 爆発 / 範囲攻撃 |
| 金 | 必殺ゲージ増加 |
| 闇 | 高火力だが被ダメ増加 |
| 星 | 全体バランス強化 |

## 6. ゲーム間リンク案

ゲーム同士は、直接ひとつに統合するのではなく、以下の仕組みでゆるく連動させる。

- 合言葉でスキン、称号、図鑑メモを解放する。
- クリアコードでゲーム間連動を行う。
- 共通キャラ図鑑を作る。
- サッグの鍛冶屋をゲーム横断の共通施設にする。

合言葉やクリアコードは、外部サービスや別ゲームから戻ってきたときにも使いやすい連動方法として扱う。

## 方針まとめ

Gの部屋のゲーム展開は、TCG、シューティング、パズルをひとつの巨大アプリにまとめるのではなく、それぞれ独立したゲームとして育てる。

そのうえで、ポータル、大陸MAP、合言葉、クリアコード、共通キャラ図鑑、サッグの鍛冶屋によって、世界観とプレイ体験をつなげていく。
